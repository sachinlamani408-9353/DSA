## 📌 Overview
This project demonstrates the implementation of the **Linear Search algorithm** using the C programming language.  
The program searches for a given element by checking each element sequentially.

---

## ⚙️ Features
✔ Easy to understand  
✔ Beginner-friendly code  
✔ User input support  
✔ Displays position of element  

---

## 🛠️ Technologies Used
- C Programming
- GCC Compiler

---

## 🚀 How to Run

### Step 1: Compile
```bash
gcc linear_search.c -o linear_search
Step 2: Execute
./linear_search
🧾 Example
Input
Enter number of elements: 5
Enter elements: 10 20 30 40 50
Enter element to search: 30
Output
Element found at position: 3
🧠 Algorithm
Start

Input number of elements (n)

Input array elements

Input search key

Traverse the array

If element found → print position

Else → print "Not Found"

End
