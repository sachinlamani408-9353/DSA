# Find Minimum Element in Array (C Program)

## 📌 Description
This program finds the minimum value from a list of integers entered by the user.

## 🧾 How it Works
1. User enters number of elements (n)
2. User inputs n integers
3. Program assumes first element as minimum
4. It compares all elements to find the smallest value
5. Displays the minimum value

## 💻 Code Features
- Uses array of size 50
- Simple loop comparison
- Efficient approach

## ▶️ Sample Input
Enter the number of elements: 5  
Enter the elements:  
10 5 20 3 15  

## ✅ Output
Minimum value of the array is: 3

## ⚠️ Limitations
- Maximum array size is 50
- No validation for invalid input
